# 常用文件夹

“常用文件夹”用于固定经常访问的目录，让桌面助手和文件口袋可以直接打开或作为复制、移动目标。它只保存目录路径和显示名称，不拥有目录，也不会因路径失效而自动删除记录。

## 常用文件夹与最近使用

- **常用文件夹**是你手动固定、命名和排序的列表；最多新增 20 条。
- **最近使用**是文件口袋在复制或移动成功后自动记录的目标，最多保留 10 条，最近使用的排在最前。
- 两个列表相互独立。同一个目录可以同时出现在两处；打开常用文件夹不会把它加入最近使用。
- 清空最近使用只清历史记录，不会影响常用文件夹或磁盘上的目录。

## 添加、命名和排序

1. 在桌面助手 QuickPanel 或文件口袋中选择“管理常用文件夹”；空列表也可以点“添加文件夹”。
2. 选择一个已经存在的目录。重复添加时会定位到现有条目并提示“已经是常用文件夹”。
3. 在条目菜单中选择“重命名”，名称会去除首尾空格，长度为 1–40 个字符。
4. 使用条目旁的上移、下移按钮调整顺序；QuickPanel 按这个顺序展示前 6 条，其余可从“查看全部”进入管理窗。

## 修改路径与移除

- “修改路径”会为同一条记录选择另一个现存目录，并保留它的 ID、名称和排序位置。
- 如果原目录被移动、拔掉了移动硬盘或网络盘暂时不可用，该条会标为“路径失效”，但仍保留在列表中。可用“修改路径”指向新位置；原位置恢复后刷新列表即可重新使用。
- “移除”只取消固定，不会删除实际文件夹及其中的文件。
- “复制路径”可复制完整路径；完整路径也会保存在条目的提示文本中。

## 从 QuickPanel 打开

QuickPanel 显示“常用文件夹”区。点有效目录会通过 Windows 系统目录打开方式打开目标；失效目录不能打开，但仍可从右键菜单复制路径、改名、修复路径或移除。打开动作不会新增最近使用记录。

## 在文件口袋中复制或移动

先在文件口袋中选择一个或多个项目，再从“常用文件夹”“最近使用”或“当前资源管理器”目标区执行“复制到这里”或“移动到这里”。成功的复制/移动继续写入最近使用记录；移动成功后，文件口袋中的对应引用会更新到新路径。遇到重名时沿用文件操作服务的自动改名策略，不覆盖已有内容；把文件操作到其当前目录会作为跳过处理，不额外制造副本。

## 数据位置

常用文件夹和最近使用共同存于应用数据目录的 `destinations.json`：源码运行时为仓库 `data/destinations.json`，打包运行时为程序旁的 `data/destinations.json`。新保存格式为 version 2；旧版无 version 的记录仍可按原顺序读取，并会在下一次保存时写成 version 2。损坏文件不会在读取时被覆盖；程序会记录 warning，并尽力在旁边保存带时间戳的 `.corrupt-*.bak` 备份。
