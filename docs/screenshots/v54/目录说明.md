# V5.4 界面验收渲染图

本目录存放大小周日历、日历按钮成功反馈和三条常用文件夹面板的 Qt 隔离渲染图，用于复核本轮布局与状态样式。

快速面板本轮最终预览为 `v54-quick-panel-redesign-final.png`：标题为“小迪助手”，含三条演示收藏。较早版本截图保留为迭代记录，不覆盖。

图片使用临时工资/目录数据，通过隐藏窗口渲染生成；它们不是用户桌面的实拍，也不证明真实鼠标、屏幕 DPI 或 Explorer 行为。不要将真实工资、个人文件名或用户目录截图放入此处。

`v54-skin-contrast-shown-widget-sakura-full.png` 是修复配色后，在 Windows Qt 平台显示 320×480 面板，再对控件抓图的结果；工资卡背景实测为 `#FEF2F6`。它验证了运行时控件样式与布局，但不等于显示器合成后的桌面截图。较小的 `v54-skin-contrast-shown-widget-sakura.png` 保留为第一次布局检查记录。
