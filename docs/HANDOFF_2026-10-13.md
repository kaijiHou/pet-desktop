## 4. 踩坑清单（按"会再犯"概率排序）

### 构建/打包类
1. **build_release.ps1 有 6 处版本钉点**：`$releaseVersion`、$auditArgs 的 baseline/summary/acceptance/extra-required、post-build 回填目标 `$summaryPath`、verify_release.ps1 的 `--version`。升版本必须全改，漏一处就在不同步骤炸
2. **pre-build 文档审计契约**：Vxx_CHANGE_SUMMARY 的 §5 文件表必须与 `git diff --name-status baseline..HEAD` 逐行一致（摘要自身豁免）；`Release built from Git HEAD:` 和 `Artifact ZIP SHA256:` 两行在 prebuild 时必须是**顶格字面 `pending`**（写成列表项 `- pending` 匹配失败，构建最后一步 throw）
3. **PowerShell 数组尾逗号** → ParserError；删行式替换要检查收尾元素
4. **PS5 写 UTF8 带 BOM** → json.load 拒读（build_info 事故）；全局规则：一律 pwsh 7，写文件显式 UTF8Encoding($false)，读端 utf-8-sig
5. **.bat 内容必须纯 ASCII + CRLF**（cmd 按 GBK 解析 UTF-8 中文会截断命令）；延时用 `ping -n 3 127.0.0.1`
6. **git diff 非 -z 模式把非 ASCII 路径输出为八进制引号**——自写校验必须用 `-z` 语义，否则中文路径文件"永远对不上"
7. **uv venv 没有 pip**：用 `uv pip install --python .venv\Scripts\python.exe 包名`
8. **venv 的 pythonw.exe 是跳板**：任务管理器见父子两个 pythonw 都带 main.py 参数，只有一个真正执行——不是双开，别误杀

### 运行时/架构类
9. **IME 崩溃红线**：半透明 Frameless+Tool 顶层窗口里跑 **Python paintEvent** 会被输入法消息重入 → Qt5Core fail-fast（0xC0000409）整个进程闪退。气泡/金额弹牌/确认卡全是**纯 QLabel+QSS 贴图，零 Python paintEvent**。新弹层一律照抄这个架构，加了 paintEvent 的测试（test_v54_money_popup / bubble）会拦
10. **DynamicPackRenderer bbox 必须格内相对并集**：这角色套装走路帧横向分布，全图绝对并集 = 4341×5388 → 锚点铺满屏 → 气泡飞屏幕中间。已加契约测试（visible_bbox ≤ 192×208）
11. **QScrollArea 方形视口**会在圆角卡片四角露"尖尖" → QuickPanel 已去外层滚动；别加回来
12. **全局 QSS 渗透不到 QComboBox 弹层**（Windows 深色模式画原生黑列表）→ ModernComboBox 在 showPopup 时把调色板钉在 view 自身
13. **QPushButton 基础 padding 8×14 会把 30px 图标钮的"＋"裁成竖杠**；QToolButton+InstantPopup 的菜单箭头要用**按钮自身 stylesheet** 的 `::menu-indicator { image: none; }` 才压得住；**全角"＋"在 30px 钮里同样被裁** → 用半角"+"
14. **编辑器保存 = 原子写（删原文件+改名）**：ShellWatcher 会收到"删除"误报 → _on_shell_event 里 350ms 合并成"检测到文件保存"（别拆）
15. **探针沙盒纪律（出过数据事故）**：任何探针必须在构造 PetWindow 前重定向**全部五个**数据面：config.CONFIG_DIR/CONFIG_FILE、reminder_service.REMINDERS_FILE、pocket_service.POCKET_FILE、**destinations.DESTINATIONS_FILE**（本轮漏了这个，覆盖了用户收藏）、wage 用 svc 构造参数。模板见各 .tmp 探针或 HANDOFF 旧版
16. **align 脚本的 band_clamp/piece_filter 是按包开关的**：gray 包开了会砍掉跑步帧的脚（鞋子和身体断开画）；绿衣两包开着防碎片
17. **角色素材 / data/ 是用户数据**：.gitignore 不追踪，探针/测试不得写入或覆盖；用户明确说过"人物形象已经改好，千万不要动角色"

### 测试类
