# V3 工资规则

## 配置

- 月工资、上班时间、午休开始/结束、收入提示间隔（关闭/10/30/60/120 分钟）和隐私模式均由用户配置。
- 未启用或月工资/上班时间缺失时，状态为“未配置”，不显示假金额。
- 工资计算工作日数优先使用手工覆盖，否则由工时日历计算。

## 正常工资

`日薪 = 月工资 / 工资计算工作日数`。

正常有效分钟为“上班时间到 17:30”减去午休重叠部分；今天已付分钟从上班时间算到当前时刻，扣除午休并封顶到 17:30。17:30 时正好达到日薪，休息日和请假日基本工资为 0，调休上班按工作日计算。

计算使用整数分钟和 Decimal，最终金额按分四舍五入。没有每秒后台累加器。

## 加班与餐补

- 17:30 后开始加班。
- 当月累计前 25 小时按 ¥15/小时，超过部分按 ¥25/小时；跨越阈值时按分钟拆分。
- 实际下班时间达到 20:00 才确认 ¥30 餐补；未打卡时只允许显示“预计 +¥30”。
- 未记录下班不会自动算到凌晨；第二天只提示一次“昨天没有记录下班时间”，用户可选择时间或标记昨天未加班。

## 日历与记录

日期状态支持工作日、休息日、调休上班、请假。优先级为手工 override > 本地节假日数据 > 周一至周五默认。恢复自动判断会删除指定日期的手工 override。

每条记录保存日期、状态、实际下班时间、加班分钟/金额、餐补、备注和手工标记。文件使用临时文件替换，损坏 JSON 静默回退到安全默认值。

## 隐私

隐私模式保留进度百分比和距离下班时间，不展示月薪、人民币金额或加班费金额；托盘提示和普通 INFO 日志不写金额。
